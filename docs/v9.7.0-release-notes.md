# AOF v9.7.0 Release Notes

## What You Can Do Now

AOF can now treat Archmap v0.4.0 as the governed architecture lifecycle projection baseline.

In practical terms, an operator can inspect how AOF work connects to:

- Requirement
- Acceptance Criterion
- Decision
- Risk
- Test
- Evidence

without making Archmap or Mission Control the source of truth. The canonical evidence remains in AOF artifacts.

## Capability Delta

NEW:

- `PCAP-ARCHMAP-LIFECYCLE-TRACEABILITY`: governed AOF work can be mapped into the Archmap v0.4 lifecycle provider model.

UPDATED:

- `PCAP-TRACEABILITY`: traceability now includes architecture lifecycle projection.
- `PCAP-PRODUCT-VALUE-COMPREHENSION`: v9.7 explains the provider upgrade as a user capability, not just an internal baseline update.

REMOVED:

- None.

## Capability Matrix

See [AOF Capability Matrix](aof-capability-matrix.md).

| Capability | v9.6 | v9.7 |
|---|---|---|
| Archmap Lifecycle Traceability | Guidance-level Archmap integration | AOF artifacts map to Archmap v0.4 Requirement / Acceptance / Decision / Risk / Test / Evidence lifecycle concepts |
| Traceability | Cost/quota chain evidence | Architecture lifecycle traceability projection added |
| Product Value Comprehension | Spend/quota value evidence required | Provider baseline explained as user-facing lifecycle traceability capability |

## Before / After

Before v9.7, AOF had Archmap integration guidance, but lifecycle traceability was not tied to the current Archmap v0.4 provider baseline.

After v9.7, AOF has a committed external reference, adoption document, authoring rule, current architecture map source update, impact evidence, and release checklist that bind Archmap v0.4 lifecycle concepts to AOF runtime artifacts.

## Five-Minute Demo

1. Read `docs/v9.7-archmap-v0.4.0-adoption.md`.
2. Open `docs/archmaps/aof-runtime-current.archmap`.
3. Find the Archmap lifecycle projection node.
4. Confirm the lifecycle mapping from AOF artifacts to Requirement / Acceptance / Decision / Risk / Test / Evidence.
5. Run `node ./src/cli.js archmap-impact-audit --project . --cutoff-task-id TASK-071`.
