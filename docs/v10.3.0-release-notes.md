# AOF v10.3.0 Release Notes

## What You Can Do Now

v10.3 gives AOF a production execution authorization model. An operator can now see the approval, budget, rollback, incident, stop, reproduction, and provider-capability gates that must exist before any future live external provider action is allowed.

This is not live provider execution. It is the permission model that blocks execution until the required gates exist and are reviewed.

## Capability Delta

NEW:

- `PCAP-PRODUCTION-EXECUTION-AUTHORIZATION-MODEL`: express the gates required before live provider execution is allowed.

UPDATED:

- `PCAP-EXTERNAL-PROVIDER-PILOT-SELECTION`: selected pilot now has an execution authorization prerequisite.
- `PCAP-PRODUCTION-READINESS-REVIEW`: readiness review now separates modeled authorization from proven production execution.
- `PCAP-EXTERNAL-RUNTIME-PRODUCTIZATION`: productization now has a clearer authority boundary.

REMOVED:

- None.

## Before / After

Before v10.3, AOF had selected GitHub read-first as the first provider pilot but did not have a single release-grade authorization model for future live execution.

After v10.3, AOF can say: no live provider action is allowed until authority, approval, budget, rollback, incident, stop, reproduction, and adapter-capability gates exist and pass review.

## Five-Minute Demo

1. Read `docs/v10.3-release-definition.md`.
2. Check the Authorization Model section.
3. Run `node ./src/cli.js release-state-audit --project .`.
4. Confirm v10.3 does not claim completed provider execution or production safety.

## Value Evidence

- Operators can reject unsafe provider actions by pointing to missing authorization gates.
- AOF separates permission modeling from live execution.
- Future provider pilot readiness has a concrete gate list instead of vague approval language.

## Not Proven

v10.3 does not prove live provider execution, provider write safety, production credential safety, billing safety, incident recovery performance, third-party validation completion, market value, or external adoption.
