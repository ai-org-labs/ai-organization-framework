# AOF v10.1 Release Definition

## Release Theme

Third-Party Operator Validation Contract.

v10.1 does not claim that third-party validation is complete. It defines what external operators must be able to reproduce, understand, challenge, and accept before AOF can make stronger external runtime claims beyond self-hosting evidence.

Human-facing wording:

> v10.1 tells an operator what outside validation must prove before AOF external runtime can claim validation beyond its own self-hosting evidence.

## What Users Can Do Now

After v10.1, a user can:

- see the required third-party validation contract for external runtime claims
- distinguish internal self-hosting evidence from external validation
- know what an outside operator must reproduce and accept
- block stronger product claims until external validation results exist
- keep live execution, market proof, and third-party acceptance outside the release claim

## Capability Delta

NEW:

- `PCAP-THIRD-PARTY-VALIDATION-CONTRACT`: AOF can define the evidence contract required for third-party operator validation.

UPDATED:

- `PCAP-EXTERNAL-RUNTIME-PRODUCTIZATION`: productization now has an explicit external validation boundary.
- `PCAP-PRODUCTION-READINESS-REVIEW`: readiness review now feeds external validation requirements.
- `PCAP-PRODUCT-VALUE-COMPREHENSION`: product claims must state whether evidence is self-hosting or third-party.

REMOVED:

- None.

## Third-Party Validation Contract

An external operator validation result must include:

- operator identity boundary and independence statement
- scenario reproduced
- commands or artifacts inspected
- what the operator understood within 30 seconds
- what failed or remained confusing
- accepted capability claims
- rejected or deferred capability claims
- explicit not-proven list
- evidence refs that a human reviewer can reconstruct

## Not Proven Boundary

v10.1 does not prove:

- completed third-party validation
- external adoption
- product-market fit
- live provider execution safety
- production credentials or billing safety
- authorization to perform external writes

## Release Decision

Release only if AOF makes it harder to confuse:

- validation contract with validation completion
- self-hosting evidence with external proof
- productization decision with market adoption
- structural audit pass with semantic truth
