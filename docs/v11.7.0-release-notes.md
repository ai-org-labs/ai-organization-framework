# AOF v11.7.0 Release Notes

## What You Can Do Now

You can see the provider-read decision state directly in Mission Control.

Instead of opening provider integration, observation replay, and external operator feedback artifacts one by one, the operator can now see:

- accepted / blocked / reopened / deferred / needs-review decision state
- feedback route that caused the state
- operator-readable summary
- next action
- evidence refs
- not-proven boundary

## Capability Delta

NEW:

- `PCAP-PROVIDER-READ-DECISION-REPLAY`: provider-read decisions are replayed into Mission Control as a governed operator-facing state.

UPDATED:

- External operator feedback now feeds a visible decision replay.
- Provider observation replay now has a downstream decision projection.

REMOVED:

- None.

## Capability Matrix

| Capability | v11.6.0 | v11.7.0 | User-visible change |
|---|---|---|---|
| Provider Read Decision Replay | no Mission Control decision projection | accepted / blocked / reopened / deferred / needs-review state visible | Operators can inspect decision state without reconstructing raw artifacts. |
| External Operator Feedback | feedback record exists | feedback route drives decision state | Feedback becomes an operational decision input. |
| Provider Observation Replay | readable replay exists | replay linked to downstream decision | Provider evidence becomes visible as part of a governed decision chain. |
