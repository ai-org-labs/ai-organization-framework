# AOF v11.4.0 Release Notes

## What You Can Do Now

You can ask AOF whether an AI work session is safe enough to count as release evidence.

The answer now depends on the actual session contract: prompt, response, tool calls, tool safety level, approval policy, task links, requirement links, test evidence, risk candidates, decision candidates, and stop condition.

## Capability Delta

| Capability | v11.3.0 | v11.4.0 | User-visible change |
|---|---|---|---|
| Agent Session Evidence | reconstructable session records existed | session records must also prove governed tool authority | operators can see whether tools were safe, approved, and linked to release evidence |
| Tool Governance Evidence | scattered across command safety and approvals | checked inside release-ready session evidence | hidden external-write permission fails closed |
| Release-State Governance | validation replay gate | validation replay plus agent-session contract gate | release readiness includes AI work-session authority |

## Capability Matrix

| Capability | Before | After |
|---|---|---|
| Agent Session Evidence | session logs were reconstructable | session logs must prove governed tool authority before release-ready use |
| Tool Governance Evidence | approval and safety were spread across artifacts | tool safety level and approval policy are checked in the session contract |
| Release-State Governance | v11.3 checked validation replay | v11.4 also checks agent-session contract evidence |

## Value Evidence

- Scenario: an operator asks whether the AI work session can be trusted as release evidence.
- Five-minute demo: open `SESS-V114-AGENT-SESSION-TOOL-GOVERNANCE.json` and `agent-session-contract-audit.json`; confirm prompt, response, tool calls, safety level, approval policy, task refs, requirement refs, test refs, risks, decisions, and stop condition.
- Work reduced: the operator no longer has to infer whether tool calls were safe or approved from prose.
- Boundary: green audit means governed structural/runtime evidence, not semantic truth or external write permission.
