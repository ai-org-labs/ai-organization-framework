# AOF v11.2.0 Release Notes

## What You Can Do Now

You can let AOF read a real GitHub repository as a governed runtime integration, not just as an ad hoc observation.

The release answers:

- どの外部Providerを読んだのか
- どの read-only adapter / resource 契約に基づいたのか
- repo / release / issue / PR / workflow run の何を観測したのか
- その観測から次に何をすべきと判断したのか
- 外部書き込みが試行・承認されていないか
- まだ証明していないことは何か

## Capability Delta

NEW: Provider Read Integration Proof.

v11.1 let a human reproduce AOF's next-task judgment.

v11.2 makes the upstream provider read itself a governed artifact with a dedicated audit gate.

## Product Value

Before: The operator could see AOF's GitHub-grounded judgment, but the provider read was not a first-class runtime integration.

After: The operator can inspect one integration record and one audit result to confirm that GitHub was read through a bounded no-write path.
