# AOF v9.9.0 Release Notes

## What You Can Do Now

v9.9 lets an operator run a bounded production readiness review for external runtime provider-backed work. The operator can see whether approval, target operation, reproduction, rollback, outcome, learning, incident recovery, cost/quota, product value, and acceptance evidence are present before considering production movement.

This is not live provider execution and not production authorization.

## Capability Delta

NEW:

- `PCAP-PRODUCTION-READINESS-REVIEW`: review whether external runtime provider-backed work is ready for human production go/no-go judgment.

UPDATED:

- `PCAP-PRODUCTION-GONOGO`: the v9.8 evidence candidate now feeds a readiness review.
- `PCAP-PROVIDER-EXECUTION`: readiness can be reviewed without granting live execution.
- `PCAP-PRODUCT-VALUE-COMPREHENSION`: release value is stated as operator capability, not audit volume.

REMOVED:

- None.

## Capability Matrix

See `docs/aof-capability-matrix.md` for the version-by-capability table.

## Before / After

Before v9.9, AOF could bundle production go/no-go evidence as a candidate.

After v9.9, AOF can present that bundle as a production readiness review with stop/defer boundaries and explicit not-proven claims.

## Five-Minute Demo

1. Read `docs/v9.9-release-definition.md`.
2. Run `node ./src/cli.js release-state-audit --project .`.
3. Confirm that the provider evidence gates pass structurally.
4. Confirm that v9.9 still refuses to claim live provider execution safety or production authorization.

## Value Evidence

- The operator no longer has to manually assemble readiness evidence from separate provider audits.
- The release gives one bounded readiness review surface.
- Stop/defer criteria are explicit before production movement.

## Not Proven

v9.9 does not prove semantic truth, market value, third-party acceptance, provider credential safety, billing safety, rollback success in production, or permission for live external writes.
