# AOF v11.3 Release Definition

## Release Name

External Validation Result Replay Audit.

## User Capability

AOF can now take an external validation result, replay how it changes confidence in a governed provider-read chain, and show whether uncertainty is accepted, escalated, blocked, or deferred.

Before v11.3, a provider read could be governed and audited, but an external validation result was not itself replayed into the decision chain. After v11.3, the validation result must point to the provider-read evidence, explain confidence before/after, preserve the no-write boundary, and route uncertainty into governance instead of hiding it.

## Mandatory Evidence

- `external-validation-replay-record`
- `external-validation-replay-audit`
- Provider read integration evidence from v11.2
- Product value evidence
- Capability release delta
- Work governance evidence
- Release-state audit including `external-validation-replay-audit`

## Release Boundary

v11.3 proves a replay contract for external validation results. It does not prove provider semantic truth, actual independent third-party validation, GitHub write safety, credential safety, production automation safety, market value, or broad adoption.
