# AOF v10.6.0 Release Notes

## What You Can Do Now

v10.6 gives AOF a third-party validation result ingestion contract. An operator can now take an external reviewer result, classify it, link it to a capability claim, and route uncertainty or rejection into governance.

This is not completed third-party validation. It is the ingestion model required before external validation results can affect release claims.

## Capability Delta

NEW:

- `PCAP-THIRD-PARTY-VALIDATION-RESULT-INGESTION`: normalize and govern third-party validation results against capability claims.

UPDATED:

- `PCAP-THIRD-PARTY-VALIDATION-CONTRACT`: the contract now has a defined result ingestion path.
- `PCAP-EXTERNAL-VALUE-REPRODUCTION-PACKAGE`: reproduction results now have a target ingestion model.
- `PCAP-PROVIDER-BACKED-WORK-LIFECYCLE-SURFACE`: lifecycle claims can point to ingested external validation status.

REMOVED:

- None.

## Capability Matrix

See `docs/aof-capability-matrix.md` for the version-by-capability table.

## Before / After

Before v10.6, AOF had a third-party validation contract and an external reproduction package, but no clear path for receiving the result.

After v10.6, AOF can say: when an external reviewer reports a result, classify it, link it to the capability claim, preserve uncertainty, and route it to Council review when needed.

## Five-Minute Demo

1. Read `docs/v10.6-release-definition.md`.
2. Check the Ingestion Contract section.
3. Run `node ./src/cli.js release-state-audit --project .`.
4. Confirm v10.6 does not claim actual external validation completion.

## Value Evidence

- External feedback no longer remains informal text outside AOF governance.
- Rejected, inconclusive, or context-mismatched results become product governance input.
- AOF can keep capability claims bounded until external results are reviewed.

## Not Proven

v10.6 does not prove actual external validation results, third-party validation completion, market value, external adoption, live provider execution, provider write safety, or production safety.
