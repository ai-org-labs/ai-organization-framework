# AOF v10.0 Release Definition

## Release Theme

External Runtime Productization Decision.

v10.0 does not authorize live provider execution. It decides whether the v9.x external runtime evidence chain is coherent enough to advance as a product-grade capability surface, or whether it should remain research-grade until more validation exists.

Human-facing wording:

> v10.0 lets an operator decide whether AOF external runtime is ready to be treated as a product capability, while clearly separating that decision from live execution permission, third-party validation, and market proof.

## What Users Can Do Now

After v10.0, a user can:

- see a Council-backed productization decision for the external runtime direction
- understand whether the v9.x provider evidence chain is coherent enough to advance
- distinguish product-grade candidate from production execution authorization
- identify which validation remains before stronger claims are allowed
- stop or defer live provider movement when third-party validation or production authorization is missing

## Capability Delta

NEW:

- `PCAP-EXTERNAL-RUNTIME-PRODUCTIZATION`: AOF can make a bounded productization decision for the external runtime capability surface.

UPDATED:

- `PCAP-PRODUCTION-READINESS-REVIEW`: v9.9 readiness review now feeds a productization decision.
- `PCAP-PROVIDER-EXECUTION`: provider execution remains blocked from live authorization, but productization direction is now explicit.
- `PCAP-PRODUCT-VALUE-COMPREHENSION`: productization must be explained as user value and remaining proof gaps.

REMOVED:

- None.

## Productization Decision

Decision: advance external runtime as a product-grade candidate surface.

Conditions:

- keep live execution authorization blocked
- require v10.1 third-party operator validation before stronger adoption claims
- require v10.2 provider pilot selection before provider-specific claims
- require v10.3 authorization model before live external writes

## Not Proven Boundary

v10.0 does not prove:

- live provider execution safety
- production credentials or billing safety
- provider semantic correctness
- actual customer impact absence
- third-party operator acceptance
- product-market fit
- authorization to perform external writes

## Release Decision

Release only if AOF makes it harder to confuse:

- productization decision with production authorization
- product-grade candidate with third-party validation
- internal self-hosting evidence with market proof
- structural audit pass with semantic truth
