# AOF v11.5.0 Release Notes

## What You Can Do Now

AOF can now replay provider observation evidence in plain operator language. Instead of opening several raw JSON artifacts to understand an external read, an operator can inspect one replay packet and see:

- what external state was read
- why it mattered
- what changed
- what remains unproven
- what should happen next

## Capability Delta

NEW:

- Human-readable Provider Observation Replay

UPDATED:

- Provider Read Integration now has an operator-facing replay layer.
- External Validation Replay now feeds a human-readable provider observation story.

REMOVED:

- None.

## Product Benchmark

Before:

- Provider evidence existed, but the operator had to manually connect observation, provider-read integration, validation replay, and release gates.

After:

- AOF produces and audits a replay record that explains the provider evidence chain without implying external write authority or provider semantic truth.

Five-minute demo:

- Run `node ./src/cli.js provider-observation-replay-audit --project .`
- Open `.aof/artifacts/provider-observation-replays/POR-TASK-136-V115.json`
- Confirm the replay explains the read, value, delta, not-proven boundary, and next action.
