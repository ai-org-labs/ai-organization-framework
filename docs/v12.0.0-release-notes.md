# AOF v12.0.0 Release Notes

## What You Can Do Now

You can review a provider-backed decision from one Mission Control console.

Mission Control now exposes a Provider-backed Operator Decision Console showing:

- proposed action
- operator Go/No-Go question
- provider decision state
- freshness status
- tool governance status
- external runtime safety status
- approval boundary
- rollback boundary
- no-autonomous-write boundary
- evidence refs

## Capability Delta

NEW:

- `PCAP-PROVIDER-BACKED-OPERATOR-DECISION-CONSOLE`: provider-backed decision evidence is joined into one operator-facing Go/No-Go surface.

UPDATED:

- `PCAP-PROVIDER-READ-DECISION-REPLAY`: feeds the Decision Console.
- `PCAP-PROVIDER-READ-FRESHNESS-REFRESH`: blocks or defers decisions when evidence is stale.
- `PCAP-TOOL-GOVERNANCE-REPLAY`: contributes tool-call governance status to the decision surface.

REMOVED:

- None.

## Capability Matrix

| Capability | v11.9.0 | v12.0.0 | User-visible change |
|---|---|---|---|
| Tool Governance Replay | tool calls governed and counted | contributes to provider decision review | Tool safety is now part of a Go/No-Go console. |
| Provider Read Decision Replay | visible as a separate replay | joined into one decision console | Operators no longer manually join decision, freshness, and safety evidence. |
| Provider-backed Operator Decision Console | not present | visible in Mission Control | Operators can decide accept/defer/reopen/block from one read-only surface. |

## Value Evidence

- Before: an operator had to inspect several Mission Control sections to decide whether provider-backed evidence could advance.
- After: Mission Control gives one decision console with evidence refs and explicit boundaries.
- Five-minute demo: run `visibility-export` and inspect `provider_backed_operator_decision_console` in `.aof/artifacts/visibility/current/mission-control.json`.
- Evidence: `.aof/artifacts/product-value-evidence/PVE-TASK-142-V120.json`.

## Runtime / CLI

- Added Mission Control `provider_backed_operator_decision_console`.
- Extended the Mission Control schema with a read-only operator decision console contract.
- Updated the Mission Control viewer to show the decision console in Japanese under proof details.
- Added regression coverage in `test/runtime-situation.test.js`.

## Not Proven

v12.0 does not prove provider truth, semantic truth, credential safety, billing safety, market value, production execution safety, or autonomous external write authority.
