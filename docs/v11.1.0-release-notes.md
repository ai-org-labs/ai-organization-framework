# AOF v11.1.0 Release Notes

## What You Can Do Now

You can ask AOF why a task is the next most important task and receive a bounded Japanese replay path that a first-time operator can inspect in five minutes.

The release answers:

- 今の状況は何か
- 候補タスクは何か
- なぜそのタスクが一番重要か
- どの証拠を見ればよいか
- Go/No-Go は何か
- まだ証明していないことは何か

## Capability Delta

NEW: External Operator Reproduction Proof.

v11.0 proved read-only GitHub observation and next-task selection.

v11.1 adds a reproduction drill so that the judgment is not just AI-internal. A human operator gets a small evidence path and can decide whether the AOF judgment is acceptable.

## Product Value

Before: The operator had to ask the AI again, or read many artifacts, to understand why AOF selected a task.

After: The operator can inspect one reproduction packet and its evidence refs.
