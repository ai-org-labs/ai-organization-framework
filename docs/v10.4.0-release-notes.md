# AOF v10.4.0 Release Notes

## What You Can Do Now

v10.4 gives AOF an external value reproduction evidence package. An operator can now hand a bounded scenario to an external reviewer and ask them to report whether AOF value is understandable, observable, accepted, rejected, inconclusive, or context-mismatched.

This is not completed external validation. It is the package required to run external value reproduction without confusing self-hosting evidence for external proof.

## Capability Delta

NEW:

- `PCAP-EXTERNAL-VALUE-REPRODUCTION-PACKAGE`: prepare a bounded package for external operators to reproduce and report user-visible value.

UPDATED:

- `PCAP-THIRD-PARTY-VALIDATION-CONTRACT`: validation now has a concrete value-reproduction package to run.
- `PCAP-PRODUCTION-EXECUTION-AUTHORIZATION-MODEL`: production execution remains blocked until external value and safety evidence exist.
- `PCAP-EXTERNAL-RUNTIME-PRODUCTIZATION`: productization can separate internal capability from externally reproduced value.

REMOVED:

- None.

## Capability Matrix

See `docs/aof-capability-matrix.md` for the version-by-capability table.

## Before / After

Before v10.4, AOF knew external value proof was needed but did not have one bounded package an outside operator could run.

After v10.4, AOF can say: use this package to reproduce value externally, capture the verdict, and block stronger claims until the result exists.

## Five-Minute Demo

1. Read `docs/v10.4-release-definition.md`.
2. Check the Reproduction Package Contract section.
3. Run `node ./src/cli.js release-state-audit --project .`.
4. Confirm v10.4 does not claim completed external reproduction or market proof.

## Value Evidence

- Operators can separate internal self-hosting evidence from external value reproduction.
- External reviewers get a bounded scenario and verdict vocabulary.
- AOF can reopen product value work when external reproduction is rejected, inconclusive, or context-mismatched.

## Not Proven

v10.4 does not prove completed external reproduction, third-party validation completion, market value, external adoption, live provider execution, provider write safety, or production safety.
