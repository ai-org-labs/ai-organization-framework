# AOF v11.7 Release Definition

## What You Can Do Now

Operators can open Mission Control and see the provider-read decision state without reconstructing raw JSON:

- whether the provider-read chain was accepted, blocked, reopened, deferred, or needs review
- which external operator feedback route caused that state
- what changed since provider observation replay
- what evidence supports the decision
- what remains not proven
- what should happen next

## Release Theme

`v11.7` makes provider read decision replay visible as an operator-facing Mission Control surface.

Before this release, AOF could record provider-read integration, replay provider observations, and ingest external operator feedback. The decision state still required the operator to open multiple artifacts and infer whether the feedback accepted, blocked, or reopened the work.

After this release, AOF records a first-class `provider-read-decision-replay-record`, audits it, and projects the result into Mission Control.

## Capability Delta

NEW:

- `PCAP-PROVIDER-READ-DECISION-REPLAY`: AOF can replay a provider-read decision into Mission Control with decision state, feedback route, operator summary, next action, and not-proven boundary.

UPDATED:

- `PCAP-EXTERNAL-OPERATOR-FEEDBACK`: feedback is now consumed by a visible decision replay instead of remaining only as raw product evidence.
- `PCAP-PROVIDER-OBSERVATION-REPLAY`: observation replay can now be connected to an operator-facing decision state.

REMOVED:

- None.

## Release Gates

1. `provider-read-decision-replay-audit` passes.
2. `release-state-audit` includes the v11.7 provider-read decision replay gate.
3. Mission Control includes `provider_read_decision_replay_projection`.
4. The v11.7 self-hosting chain includes provider-read integration, provider observation replay, external operator feedback, provider read decision replay, product value evidence, capability delta, and agent session evidence.
5. Runtime answer is backed by at least one AOF runtime command execution.

## Boundaries

This release proves a governed visibility and audit contract only.

It does not prove provider semantic truth, live provider availability, GitHub write safety, credential safety, production automation safety, market value, broad adoption, or productivity improvement.
