# AOF v11.4 Release Definition

## Capability

AOF can treat agent session logs as release-ready evidence only when the session includes governed prompt, response, tool-call, task, requirement, test, risk, decision, and stop-condition evidence.

## User-Visible Change

Before v11.4, AOF could record agent sessions and audit reconstructability, but tool calls could still be read too loosely as "the AI did work." v11.4 adds a stricter contract: a release-ready session must show what the agent was asked, what it answered, what tools it used, what authority each tool call had, what task/requirement/test evidence it links to, what risks and decision candidates it produced, and when it stopped.

## Release Scope

- Add `agent-session-contract-audit`.
- Require governed tool-call safety metadata for v11.4+ release readiness.
- Require release-ready session evidence to link task, requirement, test, artifact, risk, and decision evidence.
- Add v11.4 self-hosting evidence for `TASK-135`.
- Keep external writes outside scope unless explicitly human-approved.

## Gates

1. `agent-session-contract-audit` passes for the v11.4 session.
2. Hidden external-write permission fails closed.
3. `release-state-audit` includes `agent-session-contract-audit` for v11.4+.
4. Product value and capability delta evidence explain the user-visible improvement.
5. Local tests, smoke, organization verify, main CI, tag CI, and GitHub Release are green before closure.

## Not Proven

v11.4 does not prove semantic truth, model quality, productivity gain, enterprise compliance, live provider execution, external write safety, credential safety, or market value. It proves that release-ready agent session evidence is structurally and runtime governed.
