# AOF v11.3.0

## What You Can Do Now

You can replay an external validation result against a governed provider read and see exactly how it changes confidence.

The operator can inspect:

- which provider-read evidence was validated
- what the external validation result said
- confidence before and after the validation result
- whether uncertainty was accepted, escalated, blocked, or deferred
- why no GitHub write or production action was authorized

## Capability Delta

NEW:

- `PCAP-EXTERNAL-VALIDATION-REPLAY`: external validation results can be replayed into provider-read confidence and governance routing.

UPDATED:

- `PCAP-PROVIDER-READ-INTEGRATION-PROOF`: provider-read evidence can now be strengthened or challenged by replayed validation results.
