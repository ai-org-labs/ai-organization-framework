# AOF v10.2.0 Release Notes

## What You Can Do Now

v10.2 gives AOF a selected first external provider pilot candidate. An operator can now see why GitHub read-first provider integration is the right first pilot, what alternatives were deferred, and what remains blocked before any real external provider write or live execution.

This is not completed provider integration. It is the selection contract for the first provider pilot.

## Capability Delta

NEW:

- `PCAP-EXTERNAL-PROVIDER-PILOT-SELECTION`: choose a bounded first provider pilot candidate with rationale, alternatives, and blocked conditions.

UPDATED:

- `PCAP-THIRD-PARTY-VALIDATION-CONTRACT`: validation criteria now inform provider pilot selection.
- `PCAP-EXTERNAL-RUNTIME-PRODUCTIZATION`: productization now has a concrete first provider pilot frontier.
- `PCAP-PRODUCTION-READINESS-REVIEW`: readiness remains blocked until provider pilot evidence exists.

REMOVED:

- None.

## Capability Matrix

See `docs/aof-capability-matrix.md` for the version-by-capability table.

## Before / After

Before v10.2, AOF knew it needed external validation and provider-backed evolution, but the first provider pilot was not selected.

After v10.2, AOF can say: start with a read-first GitHub provider pilot, because GitHub is already the release/CI/tag/issue surface and can be validated before writes.

## Five-Minute Demo

1. Read `docs/v10.2-release-definition.md`.
2. Check the Selected Pilot Candidate section.
3. Run `node ./src/cli.js release-state-audit --project .`.
4. Confirm v10.2 does not claim completed provider integration or provider write authorization.

## Value Evidence

- Operators no longer have to infer which external provider should be piloted first.
- AOF separates pilot selection from integration and execution.
- Future GitHub provider pilot work has a concrete selection rationale and blocked-condition list.

## Not Proven

v10.2 does not prove completed provider integration, live execution, production safety, third-party validation completion, market value, or permission for external writes.
