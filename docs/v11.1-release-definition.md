# AOF v11.1 Release Definition

## Release Theme

External Operator Reproduction Drill.

v11.1 proves that AOF's next-task judgment can be understood and replayed by a first-time or external operator within five minutes.

## What You Can Do Now

An operator can read one bounded Japanese reproduction packet and understand:

- what AOF thinks is happening now
- which tasks were considered
- why one task is most important
- which evidence refs support the judgment
- what Go/No-Go decision is recommended
- what is still not proven

## Capability Delta

NEW: External Operator Reproduction Proof.

Before v11.1, AOF could select the next task from GitHub read-only observation, but the operator still had to trust or re-ask the AI.

After v11.1, AOF must provide a five-minute reproduction path for the judgment.

## Release Boundary

This release does not prove broad adoption, market value, semantic truth, production safety, or real third-party comprehension.

It proves a bounded self-hosting reproduction drill structure and makes that structure auditable.

## Required Gate

- `external-operator-reproduction-audit` passes.
- `release-state-audit` includes the new v11.1 gate.
- `organization-verify` passes.
- `npm test` passes.
- `npm run smoke` passes.
